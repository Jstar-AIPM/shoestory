# 上传图体检（一次调用同时做四件事）

你在检查一张用户上传的球鞋图片。请**只输出一个 JSON 对象**，不要任何解释、不要 Markdown 代码块。

## 你要判断的六件事

1. **图里是不是运动鞋**（球鞋/篮球鞋/跑鞋/板鞋等），给出置信度；
2. **图里有几只鞋**（`shoe_count`）—— 用于提醒用户"框里有多只鞋"；
3. 如果**不是鞋**，用一句很短的话描述你实际看到的主体（`subject_description`，如"马克杯""手机""人物头像"）；
4. **品牌**（`brand`）：Nike / adidas / ASICS / Jordan / New Balance / Puma / 李宁 / 安踏 等；认不出就留空；
5. **型号**（`model_name`）：如 `GEL-Nimbus 27`、`Air Force 1`、`KD 12`；认不出就留空；
6. **Logo 与鞋身文字**（用于稍后的线稿绘制）：
   - `logo.type`：标志性图形的形状描述，如"耐克勾形""三道杠""两侧交叉条纹""飞人""字母 N"；
     **只要形状能认出来就要写**，哪怕它与鞋身同色、颜色上不显眼；
   - `logo.position`：位置，如"鞋身两侧""鞋头外侧""后跟"；
   - `logo.visibility`：这个标识在**这张照片里**看不看得见形状，三选一：
     - `"full"`：形状完整、清楚可辨；
     - `"partial"`：只露出一部分，或被鞋带/角度遮挡；
     - `"none"`：这张照片的角度根本拍不到（例如正侧面看不到后跟的飞人）。
     ⚠️ **"看不看得见"指形状能不能辨认，与颜色对比无关**：
     黑色鞋上的黑色 Logo、白色鞋上的白色压印，只要形状看得出来，就是 `full`。
     我们后面要靠这个字段决定"该不该填实"与"要不要禁止编造"，请如实判断。
   - `logo.fill_required`：品牌标志性图形通常为 `true`；`visibility` 为 `none` 时必须为 `false`；
   - `texts`：鞋身上可辨认的文字/字母清单，逐条给出：
     - `text`：文字内容（如 `"GEL"`、`"AIR"`）；
     - `position`：位置描述（如 `"中底后跟处"`）；
     - `box`：这块文字在整张图里的**归一化边界框** `[x, y, w, h]`，四个数都在 0~1 之间，
       `x,y` 是左上角、`w,h` 是宽高（相对整图比例）。看不清位置就设 `null`。
     **认不出的文字不要猜、不要虚构。**


## 严格输出这个结构

```json
{
  "is_shoe": true,
  "confidence": 0.0,
  "shoe_count": 1,
  "subject_description": "",
  "brand": "",
  "model_name": "",
  "colorway": "",
  "logo": {
    "type": "",
    "position": "",
    "visibility": "full",
    "fill_required": true,
    "confidence": 0.0
  },
  "texts": [
    {"text": "GEL", "position": "中底后跟处", "box": [0.62, 0.78, 0.18, 0.06]}
  ],
  "notes": ""
}
```

## 铁律

- **不许编造**：型号、品牌、文字都要有依据；看不清就留空。宁可留空，也不要写错。
- `logo.visibility` 必须给：`full` / `partial` / `none` 三选一，不要留空。
- `texts` 里只放**确实能辨认**的文字。模糊不清的一律不放（我们的下游规则是"宁缺勿错"）。
- `shoe_count` 要数清楚：如果一张图里有多双鞋（例如商品列表页截图），如实给出数量。
- 如果主体明显不是鞋（杯子、手机、人像、宠物……），`is_shoe` 为 `false`，
  并在 `subject_description` 里用不超过 12 个字描述你看到的东西。
- 只输出 JSON，不要输出任何其它文字。
